# Security Policy

## Supported Versions

The following versions of `dn-mac` currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security and software supply chain integrity seriously. If you discover a vulnerability or security flaw in `dn-mac`, please follow responsible disclosure guidelines:

1. **Do not create a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories at:
   - https://github.com/nelsondiego/environment-macos/security/advisories/new
   - Or contact the maintainer directly through GitHub: [@nelsondiego](https://github.com/nelsondiego).

### What to Include in Your Report
- A description of the issue and potential impact.
- Exact reproduction steps, sample commands, or proof of concept.
- Your macOS architecture (Apple Silicon / Intel) and Node.js version.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- A patch will be prioritized, tested, and released under a new semver version on npm and GitHub.
